# ARIA (RIA v2) — VS Code Extension

Exposes deterministic repository intelligence capabilities (Search, Query, Context Assembly, Grounded Answering) directly within VS Code.

## Commands

- `RIA: Ask Repository`: Natural language grounded Q&A.
- `RIA: Explain Symbol`: Instant explanation of symbol definition and usage.
- `RIA: Find Definition`: Navigate directly to exact semantic definition.
- `RIA: Find References`: List all references to active symbol.
- `RIA: Show Call Graph`: Visualize callers and callees.
- `RIA: Explain Module`: Overview of current file module dependencies.
- `RIA: Explain Repository`: System architecture overview.
- `RIA: Repository Chat`: Interactive side-panel chat.
- `RIA: Context Explorer`: Inspect assembled semantic context package.
- `RIA: Repository Status`: Check sync state and indexing metrics.
